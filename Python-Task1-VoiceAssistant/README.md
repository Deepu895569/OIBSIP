# Voice Assistant

Python Programming Internship — Oasis Infobyte (OIBSIP)

## Project Overview
A voice assistant built using Python that recognizes voice commands and responds using text-to-speech.

## Features
- Voice input and speech recognition
- Text-to-speech responses
- Current date and time
- Google search
- Error handling for unrecognized commands

## Technologies Used
- Python
- SpeechRecognition
- Pyttsx3
- SoundDevice
